⚙️ GitHub Repo सेटिंग्स (एक बार सेट करें)
Token कभी भी कहीं भेजा नहीं जाता सिवाय सीधे GitHub API के, और सिर्फ आपके browser की इस tab में रहता है (page बंद करने पर मिट जाता है)। बनाने का तरीका: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new → केवल इस repo को select करें → Repository permissions में "Contents" को "Read and write" और "Actions" को "Read-only" करें।
पेज रेंज अपने आप detect हो जाएगी (PDF के footer से) — कुछ भरने की ज़रूरत नहीं।
